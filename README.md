# 동축 케이블은 왜 50Ω일까 (coax-50-ohm)

동축 케이블의 특성 임피던스가 무엇이고, 케이블 치수에서 어떻게 정해지며, 송신용 케이블이 왜 50Ω으로 만들어지는지를 그림과 실험 상자로 설명하는 한 페이지짜리 HTML 해설입니다.

## 구성

1. 케이블은 가두고, 안테나는 내보낸다 — 그림 「층 구조」「케이블 vs 안테나」「전류의 왕복 경로와 실드 바깥면 전류」, 공통 모드 전류 상자
2. 동축 케이블 안에서 일어나는 일 — 그림 「전압→전기장→전류→자기장 4단계」, 실험 ① 케이블 속 진행파(단면·옆모습, 전기장·자기장·전자)
3. 작은 콘덴서와 작은 코일의 사다리 — 그림 「케이블 토막 = 회로 한 칸」「전송 선로의 등가 회로」, L′·C′, 속도 계수
4. 특성 임피던스는 저항이 아니다 — Z₀ = √(L′/C′) = V/I, 실험 ② 진행파의 전압과 전류
5. 케이블 치수가 임피던스를 정한다 — Z₀ = (60/√εr)·ln(D/d), 케이블 표(RG-58·RG-213·LMR-400·RG-6·5D-2V 등)
6. 중심 도체를 가늘게 하면 — 그림 「굵은 vs 가는 중심 도체」, 실험 ③ 지름 비 D/d와 손실·전압·전력
7. 표피 효과와 도체 손실: 77Ω — 실험 ④ 표피 효과, 그림 「Z₀가 너무 낮을 때/높을 때」「도체 손실 U자 곡선」, 손실 최소점 D/d ≈ 3.59 유도
8. 중심 도체를 굵게 하면: 절연 파괴와 30Ω — 그림 「가늘 때/적당할 때/너무 굵을 때」, 60Ω(전압)·30Ω(전력) 유도
9. 30Ω과 77Ω 사이의 50Ω — 비교표, 그림 「임피던스 축 위의 30·50·60·75·77Ω」, 벨 연구소 이야기(이론적 최적점과 실제 정착 배경 구분), 폴리에틸렌 케이블의 51Ω
10. 무선국에서 50Ω이 뜻하는 것 — 100 W의 전압·전류, 반사파와 SWR(무선 공식 2편으로 연결)
11. 정리: 50Ω 한 장 요약

듣기는 「교과서 속 공식」「허수 j」와 같은 방식입니다. 맨 위의 ▶ 처음부터 듣기, 단원마다 ▶ 이 단원 듣기 버튼이 있고, 아래 재생 막대에서 이전·다음 문단, 일시정지, 속도(0.8~1.2×)를 조절합니다. 대본(68문단, 1.0×에서 약 40분)은 화면 글이 아니라 따로 쓴 해설이며, 읽는 문단으로 화면이 따라가고 실험 상자도 대본에 맞춰 움직입니다. 앱 안 브라우저(카카오톡 등)에서는 브라우저로 여는 안내가 나옵니다.

## 게시

주소: https://kooking0-jh.github.io/coax-50-ohm/

1. GitHub에서 새 저장소 `coax-50-ohm` 생성 (Public)
2. `index.html`, `README.md`, `tistory-embed.html` 업로드
3. Settings → Pages → Branch: `main` / `(root)` → Save
4. 1~2분 뒤 주소 접속 확인

티스토리에는 `tistory-embed.html`의 코드를 글의 HTML 모드에 붙여 넣습니다(높이 자동 맞춤, 목차 링크·듣기 때 블로그 화면 따라가기). 블로그(iframe) 삽입 규약은 antenna-types 규약을 그대로 씁니다.

`index.html` 하나로 동작하며 외부 라이브러리가 없습니다.

## 확인한 환경

- 화면 폭 1280 / 768 / 375 / 320 px에서 가로 넘침 없음, 콘솔 오류 없음
- 비교 그림은 넓은 화면에서 나란히, 폭 560 px 이하에서는 위아래로 쌓임
- 실험 상자 4개는 폭에 따라 좌우 배치 ↔ 위아래 배치로 바뀌고, 고해상도 화면(레티나)에서 선명하게 그림
- iframe 삽입 시 높이 자동 맞춤(늘어남·줄어듦), 목차 링크 이동, 듣기 재생 막대 위치 확인
